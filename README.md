# Test Scripts for Quiz 3, Bioinf6200

### This project is a collection of scripts used for quiz 3 in my bioinformatics programming class. While they are rather simplistic scripts, I have them organized and saved as a project because a) I needed to test them and thus had them typed out, b) so I could refer back to them as needed to review the concepts, and c) because the kwarg script is a neat little interactive code that I am going to share with my literature/grammar mentor.

### Files within the Project

This project contains 2 test scripts:

#### **repetitive_test_script_quiz_3.py**
* this file takes a list of 3 string elements, 'A', 'B', & 'C', combines them, and repeats the result 3 times in-line, such that the output is 'ABCABCABC'. I presume this is practice for working with FASTA files.


#### **kwarg_test_script_quiz_3.py**
* this file takes a positional parameter, name, and an unknown number of keyword argruments in a function called command_line. It returns a declaration about a book that was read, along with all the attributes pertaining to the book. It is an exercise in working with **kwargs.
